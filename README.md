# Jafar Bakhshaliyev Website

This repository contains the source for my personal website hosted on GitHub Pages.

## Live site

- `https://jafarbakhshaliyev.github.io/`

## Local preview

Open `index.html` with Live Server, or run a simple static server from the repo root:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/` in your browser.

## Main files

- `index.html` - homepage
- `cv.html` - CV page
- `blogs/` - blog pages
- `books/` - books page
- `css/` - site styles
- `js/` - site scripts

## Notes

- GitHub Pages serves the pushed `main` branch from the repository root.
- If the site looks different locally, hard refresh the browser to clear cached assets.
